# plusコマンド
![test](https://github.com/j4059bet-sketch/python-practice/actions/workflows/test.yml/badge.svg)

標準入力から読み込んだ数字を足す。

##使い方
以下のように標準入力から数字を渡すと、合計が出力されます。

	$ seq 5 | ./plus
	15

## ライセンス
* このソフトウェアパッケージは，3条項BSDライセンスの下,再頒布および使用が許可されます。

## 必要なソフトウェア
* Python
  * テスト済み: 3.7〜3.10

## テスト環境
* Ubuntu
